================================================================================
2026 FIFA WORLD CUP — STADIUMS, VENUES & COORDINATES
================================================================================

The 2026 FIFA World Cup is co-hosted by the United States, Canada, and Mexico
across 16 venues in 16 host cities. For commercial reasons, FIFA has rebranded
each stadium with a host-city name during the tournament (e.g. MetLife Stadium
is "New York New Jersey Stadium", SoFi Stadium is "Los Angeles Stadium"). Both
names are listed below.

NOTE: The match schedule PDF lists only the host country in the "Venue" column.
This file provides the specific stadium for each match based on FIFA's confirmed
fixture list.
